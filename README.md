# Hi, I'm Maher.

I'm a software engineer based in Amman, Jordan, with a focus on backend development. I’m most interested in how a service behaves beyond the happy path: how it handles authentication, keeps data consistent, and stays maintainable as it grows.

Most of my recent work has been with **Java and Spring Boot** and **Python with FastAPI**. I also like getting involved in the surrounding pieces—databases, caching, testing, containers, and deployment—rather than treating them as an afterthought.

## A couple of projects

### InternQuest — AI-powered internship matching
A platform designed to help students find relevant internships by matching their resumes to job requirements. I worked on the backend and the integration with an NLP matching service, alongside authentication, role-based access, resume parsing, notifications, and an admin dashboard.

**Highlights:** BERT and TF-IDF matching; a three-layered architecture; JWT authentication and RBAC.

### [FeatureFlag — self-hosted feature flag service](https://github.com/amadeusVIII/featureflag)
A feature flag management system built around fast evaluations and keeping cached values consistent across API instances. The part I found especially interesting was combining local SDK caching with Redis and Pub/Sub so updates could propagate without making every evaluation depend on a network request.

**Highlights:** Spring Boot; Redis caching and Pub/Sub; a lightweight Java SDK; Terraform and CI/CD.
